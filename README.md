# Family Fitness Challenge

A [Chickadee Bandit](https://chickadeebandit.com/app-library/family-fitness-challenge) app.

Run step, distance, or activity challenges with individual or team leaderboards, in-challenge streaks, and badges. Manual entry to start.

## Features

- Step, distance, or activity challenges.
- Individual or team leaderboards.
- In-challenge streaks and badges.
- Manual entry.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-fitness-challenge/releases/latest/download/bundle.json
```

## Development

See the [app-template](https://github.com/firebirdsystems/chickadeebandit-app-template) for build instructions and the full manifest field reference.
